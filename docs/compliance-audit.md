# Automated Compliance Audit Report Templates

This document details the automated compliance verification specifications:

- **SOC 2 Type II**: Security audit logging endpoint `/api/compliance/soc2/audit-logs`.
- **PCI-DSS Level 1**: Primary account number masking test harness.
- **FERPA & COPPA**: Child consent validation and student PII redaction rules.
- **HIPAA**: Electronic Protected Health Information (ePHI) de-identification.
