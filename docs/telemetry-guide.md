# Performance & Telemetry Benchmarks Guide

This guide details the telemetry probes and $O(n^3)$ algorithm evaluation metrics supported by the Clean Architecture testbed.

- `/api/performance/cubic-complexity`: Evaluates cubic complexity algorithms.
- `/api/performance/n-plus-one`: Identifies N+1 query loop anti-patterns.
- `/api/performance/memory-telemetry`: Profiles memory usage without leaks.
- `/api/performance/soak`: Soak test telemetry endpoint.
- `/api/performance/spike`: High-concurrency spike handling verification.
